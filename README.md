My main project right now is **[Daypage](https://github.com/raphaelferreiralopes/daypage)**, a full-stack journaling and productivity app with a daily journal, habit tracking, goals and time tracking. It's built with Node.js, Express and Supabase (Postgres with row-level security), and the frontend is vanilla JavaScript.
